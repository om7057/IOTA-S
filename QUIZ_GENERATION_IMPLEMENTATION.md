# Quiz Auto-Generation & Story Persistence System

## Overview
This system automatically generates educational quizzes for every story created, using Google Gemini API for LLM-powered question generation. All quiz data is persisted to the database, ensuring no progress is lost across app restarts.

## Components

### 1. Quiz Generator Service (`/server/services/quizGenerator.js`)
- **Function**: `generateQuizFromStory(storyData, storyId)`
- **Features**:
  - Calls Google Gemini API (gemini-2.5-flash) with story content
  - Implements retry logic (3 attempts with exponential backoff)
  - In-memory caching with 1-hour TTL (uses node-cache)
  - Fallback demo quiz when API is unavailable
  - Automatic option text sanitization (removes emoji/symbols)
  - Response parsing with markdown code block support

- **Input**:
  ```javascript
  {
    title: "Story Title",
    description: "Story summary",
    content: "Full story narrative",
    category: "anxiety|depression|social|academic|family|health|identity|general"
  }
  ```

- **Output**:
  ```javascript
  {
    title: "Story Title - Learning Quiz",
    description: "Test your understanding...",
    category: "anxiety",
    difficultyLevel: "beginner|intermediate|advanced",
    timeLimit: 10,
    passingScore: 70,
    questions: [
      {
        question: "Question text?",
        type: "multiple-choice|true-false",
        options: ["Option A", "Option B"],
        correctAnswer: "Option A",
        points: 20,
        explanation: "Why this is correct..."
      }
    ]
  }
  ```

### 2. Data Sanitization Utilities (`/server/utils/sanitization.js`)
- **Functions**:
  - `normalizeOptionText(text)` - Remove leading emoji from single option
  - `sanitizeStoryOptions(options)` - Sanitize array of options
  - `sanitizeStoryJson(storyJson)` - Recursively sanitize story scenes/choices
  - `sanitizeChallengeOptions(options)` - Sanitize lesson challenge options

- **Regex Used**: `/^[\s\uFE0F\u200D\p{Extended_Pictographic}✓✔✗✕☑☒]+/gu`
  - Removes Unicode extended pictographics (emoji)
  - Removes variation selectors and zero-width joiners
  - Removes common check/cross symbols

- **Applied At**:
  - NewsStory model: Before create/update (hooks)
  - Story model: Can add hooks if needed
  - Challenge model: Before create/update (hooks)

### 3. Quiz Controller Updates (`/server/controllers/quiz.js`)
- **New Function**: `saveGeneratedQuiz(quizData, storyId)`
  - Creates Quiz record with metadata linking to storyId
  - Bulk creates associated QuizQuestion records
  - Tags quiz as 'auto-generated', 'story-quiz'
  - Returns saved quiz with questions

- **New Endpoint**: `POST /api/quizzes/generate/for-story` (Admin only)
  - Manually trigger quiz generation for a story
  - Request body: `{ storyId, storyData: { title, description, content, category } }`
  - Returns: Generated quiz with all questions

### 4. News Stories Controller Enhancement (`/server/controllers/news-stories.js`)
- **Modified**: `createNewsStory(req, res)`
  - Creates the story first
  - Triggers async quiz generation in background (non-blocking)
  - Returns story immediately while quiz generation happens

- **Helper**: `generateQuizForStoryAsync(newsStory)`
  - Calls quiz generator with story data
  - Saves quiz to DB via `saveGeneratedQuiz()`
  - Logs success/failure (graceful handling)

### 5. Model Updates

#### NewsStory Model (`/server/models/NewsStory.js`)
```javascript
hooks: {
  beforeCreate: (newsStory) => {
    // Sanitizes storyJson (removes emoji from scene options)
    if (newsStory.storyJson) {
      newsStory.storyJson = sanitizeStoryJson(newsStory.storyJson);
    }
  },
  beforeUpdate: (newsStory) => {
    // Only sanitizes if storyJson changed
    if (newsStory.changed('storyJson') && newsStory.storyJson) {
      newsStory.storyJson = sanitizeStoryJson(newsStory.storyJson);
    }
  }
}
```

#### Challenge Model (`/server/models/Challenge.js`)
```javascript
hooks: {
  beforeCreate: (challenge) => {
    // Sanitizes lesson challenge options
    if (challenge.options && Array.isArray(challenge.options)) {
      challenge.options = sanitizeChallengeOptions(challenge.options);
    }
  },
  beforeUpdate: (challenge) => {
    if (challenge.changed('options') && challenge.options) {
      challenge.options = sanitizeChallengeOptions(challenge.options);
    }
  }
}
```

### 6. Database Tables (Existing)
- **quizzes** - Stores quiz metadata
  - Fields: id, title, description, category, difficultyLevel, timeLimit, passingScore, isPublished, questionCount, totalPoints, metadata (JSONB), tags (JSONB)
  - metadata.storyId: Links quiz to source story
  - metadata.autoGenerated: Marks LLM-generated quizzes

- **quiz_questions** - Stores individual questions
  - Fields: id, quizId, sequence, type, question, options (JSONB), correctAnswer, points, explanation, hints

- **quiz_progress** - Tracks user quiz attempts
  - Fields: id, userId, quizId, attempt, completed, score, timeSpent, answers

## Data Flow

### Story Creation with Auto-Quiz Generation
```
1. POST /api/news-stories { title, description, content, storyJson, ... }
   ↓
2. NewsStory Controller creates story record (sanitizes storyJson)
   ↓
3. Return response immediately
   ↓
4. [ASYNC] Call generateQuizFromStory(storyData, storyId)
   ↓
5. Quiz Generator calls Gemini API with story content
   ↓
6. Parse response, normalize structure, sanitize options
   ↓
7. saveGeneratedQuiz() creates Quiz record + bulk creates questions
   ↓
8. Quiz persisted to DB with link to original story (metadata.storyId)
```

### Quiz Retrieval
```
GET /api/quizzes/story/:storyId
↓
Check if quiz exists with metadata.storyId = storyId
↓
Return quiz with all questions (from quiz_questions table)
↓
User can take quiz immediately (no loss across app restarts)
```

### Data Persistence
```
All quiz data stored in PostgreSQL:
- Quiz definitions in 'quizzes' table
- Questions in 'quiz_questions' table  
- User attempts in 'quiz_progress' table
- Foreign keys ensure referential integrity
- Deletions cascade properly on story/quiz removal
```

## Configuration

### Quiz Generation
- **Model**: gemini-2.5-flash
- **Retry attempts**: 3
- **Retry delay**: 2s with exponential backoff
- **Cache TTL**: 1 hour
- **Demo questions**: 4 comprehensive questions (fallback)
- **Question count**: 4-6 (from LLM)
- **Time limit**: 10 minutes (configurable)
- **Passing score**: 70% (configurable)

### Option Sanitization
- Applied at: Data layer (before database save)
- Targets: Story options, Challenge options, Quiz options
- Regex: Removes leading emoji, variation selectors, symbols
- Frontend: Also has display-time sanitization as belt-and-suspenders

## Error Handling

### API Unavailable
- Falls back to demo quiz (4 generic questions)
- Story still saves successfully
- User can still take demo quiz

### Retry Logic
- Max 3 attempts with exponential backoff
- Logs each failure attempt
- Graceful degradation after max retries

### Database Errors
- Transaction rolled back on failure
- Error logged and reported
- User notified with appropriate message

## Troubleshooting

### Quiz not generating
- Check GEMINI_API_KEY is set
- Check server logs for API errors
- Fall back quiz should still appear

### Options showing emoji
- Verify sanitization hooks are applied in models
- Check database directly: `SELECT options FROM quiz_questions LIMIT 1`
- Frontend regex may also be removing if data-layer sanitization failed

### Quiz not persisting
- Verify quiz_questions table has records
- Check foreign key relationships
- Review PostgreSQL logs for constraint violations

### Cache issues
- Clear cache: `DELETE FROM node_cache` (estimated)
- Or restart Node server to clear in-memory cache
- Cache TTL is 1 hour by default
